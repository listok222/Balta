# Балта — 3D Landing

Премиальный scroll-driven 3D-сайт для бренда «Балтика».

**Live:** https://listok222.github.io/Balta/

## Особенности

- Фотореалистичная 3D-банка (процедурная + PBR + конденсат)
- Банка «съезжает» по наклонной ледяной траектории при скролле
- Камера следует по кривой CatmullRom
- GSAP ScrollTrigger для всех анимаций
- Секции: Hero, Сорта, История, Как варится, Где купить, 18+
- Age-gate
- Палитра: фирменный синий + золото + холодный лёд
- Оптимизация под мобильные

## Технологии

- Three.js r170 (CDN)
- GSAP 3 + ScrollTrigger
- Vanilla JS (ES modules)
